## Write a python program to read two integers and perform simple arithmetic calculation.(+,-,*,/,//,%,**)

#Aim 
```
To Write a python program to read two integers and perform simple arithmetic calculation.(+,-,*,/,//,%,**)

```
#algorithm.
```
1. Start.
2. Input two integer numbers `a` and `b`.
3. Compute results using `+, -, *, /, //, %, **`.
4. Output all the results
```
##program
```
a=eval(input())
b=eval(input())


print(a+b)
print(a-b)
print(a*b)
print(a/b)
print(a//b)
print(a%b)
print(a**b)
```
